**PMO Platform**

**Project Overview:**
This is a Project Management Office (PMO) platform backend built using FastAPI. It provides a secure, role-based system for managing users, clients, and projects.
Users & Roles: Supports Super-admin, Admin, and Employee roles with different permissions.
Authentication: Secure login with JWT and optional Multi-Factor Authentication (MFA).
Client Management: Super-admins and Admins can add and manage clients.

API-first Design: Exposes RESTful endpoints for frontend applications (React, Angular, etc.).
